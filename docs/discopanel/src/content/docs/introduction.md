DiscoPanel is a self-hosted, Docker-powered Minecraft server manager. It handles server creation, modpack installation, proxy routing, backups, and multi-user access control through a web interface.

## The web interface

A few things that make the panel quick to use:

- **Global search** — press `Ctrl+K` (or `Cmd+K`) anywhere to jump to servers, players, modpacks, modules, and settings.
- **Dashboard** — the home page shows what's running, including who's online right now.
- **Quick Edit Config** — in a server's Overview tab menu, a fast editor for common config files without digging through the file browser.

For a full feature overview, see the [project README](https://github.com/nickheyer/discopanel).
